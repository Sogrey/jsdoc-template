# JSDoc 配置文件说明

本目录包含 JSDoc 文档生成器的配置文件和相关脚本。详细的构建指南请参考项目根目录的 [QUICKSTART.md](../../QUICKSTART.md)。

---

## 配置文件说明

本目录下包含两个 JSDoc 配置文件：

### 1. `conf.json` - 基础配置文件（静态，提交到 Git）

这是 JSDoc 的基础配置模板，不包含动态版本号。此文件会提交到版本控制中。

**用途**：作为 JSDoc 配置的模板和参考

**特点**：
- 不包含版本号
- 可以修改基础配置（如输出目录、模板路径等）
- 修改后需要重新生成 `conf.generated.json` 才能生效

**主要配置项**：
```json
{
  "source": {
    "include": ["src/sdk"],          // 源代码目录
    "includePattern": ".+\\.js(doc)?$"  // 包含的文件模式
  },
  "templates": {
    "cleverLinks": true,              // 智能链接
    "default": {
      "outputSourceFiles": false       // 不输出源文件
    }
  },
  "opts": {
    "destination": "Build/Documentation",  // 输出目录
    "template": "./scripts/jsdoc/jsdoc_template",  // 自定义模板
    "recurse": true                    // 递归处理子目录
  }
}
```

---

### 2. `conf.generated.json` - 生成的配置文件（动态，不提交到 Git）

这是由 `generate-config.mjs` 脚本自动生成的配置文件，在基础配置上添加了项目版本号。

**生成时机**：每次运行 `npm run docs` 或 `npm run docs:serve` 时

**生成位置**：通过 `package.json` 中的 `docs` 脚本：
```json
"docs": "node scripts/jsdoc/generate-config.mjs && npx jsdoc --configure scripts/jsdoc/conf.generated.json --pedantic"
```

**特点**：
- 包含从 `package.json` 读取的版本号
- 包含生成时间戳和来源说明（`_generatedAt` 和 `_source` 字段）
- 被 `.gitignore` 忽略，不提交到版本控制
- JSDoc 实际使用的配置文件

**额外字段**：
```json
{
  // ... 其他配置 ...
  "version": "0.0.0",              // 从项目根目录的 package.json 读取
  "_generatedAt": "2025-01-16T10:30:00.000Z",  // 生成时间
  "_source": "Generated by generate-config.mjs from conf.json"  // 来源说明
}
```

---

## 配置文件流程

```
1. 基础配置：conf.json (Git 管理，版本控制)
         ↓
2. 生成配置：generate-config.mjs (读取 package.json 中的 version)
         ↓
3. 生成结果：conf.generated.json (包含版本号 + 时间戳)
         ↓
4. 生成文档：npx jsdoc --configure conf.generated.json --pedantic
         ↓
5. 输出文档：Build/Documentation/ (显示正确的版本号)
```

---

## 相关脚本

### `generate-config.mjs`
JSDoc 配置生成脚本，负责：
- 读取项目 `package.json` 获取版本号
- 读取基础配置 `conf.json`
- 合并生成 `conf.generated.json`
- 添加生成时间戳和来源说明

---

## 修改配置

### 修改基础配置
1. 编辑 `conf.json`
2. 下次运行 `npm run docs` 时会自动重新生成 `conf.generated.json`

### 更新版本号
- **不需要手动修改配置文件**
- 直接修改项目根目录的 `package.json` 中的 `version` 字段
- 运行 `npm run docs` 即可自动同步

### 修改输出目录或其他配置
编辑 `conf.json` 中的 `opts.destination` 或其他配置项

---

## 注意事项

- ✅ **不要手动修改** `conf.generated.json`，因为它会在每次生成文档时被覆盖
- ✅ **不要提交** `conf.generated.json` 到 Git（已在 `.gitignore` 中配置）
- ✅ **版本号显示**：版本号会在 JSDoc 生成的文档首页（`indexLayout.tmpl`）中显示
- ⚠️ **修改模板**后，需要重新生成配置和文档才能看到效果

## 相关文件

- `tmpl/` - JSDoc 自定义模板目录
- `static/` - JSDoc 静态资源目录（样式、脚本等）
- `indexLayout.tmpl` - 文档首页布局模板（显示版本号）
